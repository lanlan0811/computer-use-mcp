## computer-use v0.1.0

**Windows computer use MCP server** — first release. Full desktop automation for any MCP-capable agent (Trae, Claude Code, Cursor, Cline, Cherry Studio): screenshot, mouse, keyboard, clipboard, and app control. Pure TypeScript, zero Python dependencies, standard MCP over stdio.

**Windows computer use MCP 服务器首个版本。** 让任意支持 MCP 的 Agent 应用获得完整的 Windows 桌面自动化能力。纯 TypeScript 实现，零 Python 依赖、零外部解释器。

### Install / 安装

```bash
npx @lotteai/computer-use
```

```json
{
  "mcpServers": {
    "computer-use": {
      "command": "npx",
      "args": ["-y", "@lotteai/computer-use"]
    }
  }
}
```

### Highlights / 亮点

- **22 tools** — screenshot / zoom / five click variants / type / key / scroll / drag / move / open app / switch display / clipboard read+write / wait / cursor position / hold key / mouse down+up / batch
- **Physical input interference detection** — low-level `WH_KEYBOARD_LL`/`WH_MOUSE_LL` hooks tell the agent's tagged `SendInput` apart from your physical input, with asymmetric failure semantics: "not sent, safe to retry" vs "sent, outcome unknown — do NOT retry"
- **Delivery pre-checks** — refuses off-screen coordinates and unreachable windows before sending; would rather refuse than report a success that never happened
- **Image-budget pre-scaling** — 28 px/token, 1568 px edge/token cap, so the model reads coordinates in the same space the server uses
- **Damped-spring cursor**, per-character Unicode typing (25 ms pacing), multi-monitor support with automatic target resolution, per-monitor-v2 DPI awareness, registry + UWP app discovery
- **Cross-process file lock**, full cancellation semantics with automatic held-key release, per-action batch gating
- **Crash-isolated worker** — restart after a crash always reports "outcome unknown, take a screenshot first", never a silent retry

### Parity / 复刻说明

Faithful replication of [cc-haha](https://github.com/lanlan0811/cc-haha)'s Windows pixel surface. Tool schemas, coordinate transforms, image budget, key blocklist, interference detection, and error-code semantics are verified 1:1 by snapshot contract tests against cc-haha's authoritative definitions; the only transformation is the semantic tool renaming. Seven documented deviations live in [docs/PARITY.md](https://github.com/lanlan0811/computer-use-mcp/blob/main/docs/PARITY.md).

完整复刻 cc-haha 的 Windows 像素面；schema、坐标换算、图像预算、黑名单、干扰检测、错误码语义由快照契约测试自动验证与 cc-haha 权威定义一致，唯一变换是工具名的语义化重命名；7 处显式偏差见 docs/PARITY.md。

### Safety / 安全

Fixed gate order on every call (fail-closed): kill switch → argument validation → cross-process lock → foreground identification → delivery pre-checks → execution. System shortcut blocklist (`ctrl+alt+delete`, `alt+f4`, `alt+tab`, `win+l`, `win+d`) gated behind `COMPUTER_USE_ALLOW_SYSTEM_KEYS`. Model-facing safety boundaries are baked into the MCP `instructions`. See [docs/SAFETY.md](https://github.com/lanlan0811/computer-use-mcp/blob/main/docs/SAFETY.md).

每次调用按固定顺序过门禁（fail-closed）；系统快捷键黑名单按授权位控制；写给模型的安全边界（密码变更、转账、证书警告等交回用户）已写入 instructions。详见 docs/SAFETY.md。
